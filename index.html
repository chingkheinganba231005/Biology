Start with no biology at all. Finish able to analyse genomes, single cells and tumours, simulate molecules and cells, and run a computational drug-discovery project, on real data, in Python.

How every chapter works

Plain words firstEvery idea starts with a like-you're-five explanation, then the real biology, then the maths and code.
Interactive modelsPlaygrounds where you translate genes, fold proteins, run PCR or grow a tumour and watch what happens.
Real dataGenomes from NCBI, proteins from UniProt and the PDB, drugs from ChEMBL, tumours from TCGA and real single-cell data, saved so everything also runs offline.
A notebook you runEach chapter is also a Jupyter notebook that reproduces every number and figure.

Running the notebooks

python3 -m pip install -U jupyter numpy pandas matplotlib scipy scikit-learn biopython rdkit requests
jupyter notebook

Each chapter folder holds index.html (the guide), a notebook, images/, datasets/ and animations/ (playgrounds). Guides and notebooks are generated from one source, chapter.md, by tools/build.py.

Educational material. Nothing here is medical advice.
